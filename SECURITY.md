# Security policy

Please **do not open public issues for vulnerabilities.** Report them privately through
[GitHub security advisories](https://github.com/ptnghia/cms-content-agent/security/advisories/new).
You should get a reply within a few days.

In scope: token verification and CORS, conversation isolation between users or sites, path traversal in
workspaces or the outbox, ways for the agent to escape the workspace or publish without review, and
injection through synced website content.

Deployment hardening checklist: [docs/DEPLOY.md](docs/DEPLOY.md#bảo-mật-cần-nhớ).
