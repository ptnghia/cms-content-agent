# Content plan & brief

Data: `posts/stats.md`, `site/inventory.md`, `seo/keywords.md`, `seo/audit.md`. If there is no search volume or ranking data, do not invent it; prioritise by real facts (low-scoring pages, keywords with no target page, pages not updated for a long time).

Plan (write to `plans/<name>.md`):
1. **Current state** in 3–5 bullets: number of posts, which areas are dense or thin, recurring issues.
2. **Gaps**: keywords or topics with no target page; groups of pages with overlapping intent that should be merged or given separate roles.
3. **Proposal list** (table): topic | main keyword | search intent | type (new post / optimise existing post) | priority (high/medium/low) | reason, based on which data.
4. **Schedule** by week if the user asks for one; default 4–8 items, each doable in one writing pass.

Brief for one post (write to `drafts/brief-<slug>.md`): goal, reader, search intent, main / secondary keywords, H2/H3 outline, questions to answer, internal links to include, facts the user must provide, length.
