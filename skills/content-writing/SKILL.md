# Writing a new post

1. **Check for duplicates first**: compare the topic with `site/inventory.md` / the page inventory. If it overlaps with an existing page, choose a different angle or suggest optimising that page, and say so clearly.
2. **Identify the search intent** (informational / comparison / purchase) and the reader; choose 1 main keyword + 3–6 secondary keywords.
3. **Outline** before writing: H2s in the order the reader needs them, each H2 answering one specific question; use H3 only when a section needs splitting.
4. **Write**:
   - Introduction of 2–3 sentences: get straight to the point, include the main keyword, say clearly what the post helps with.
   - Body: short paragraphs, concrete examples, lists / tables for comparisons; tone follows `knowledge/style-guide.md`.
   - Conclusion: summarise the main points + one next step (a link to a related page or a contact).
   - FAQ section (3–5 questions) if suitable; answer directly in the first sentence.
5. **Do not invent**: statistics, prices, locations, reviews, quotes. If facts are missing, write at the level of general guidance and note what needs to be added.
6. Include meta: title, description, keyword; 2–4 internal links to pages that exist.
